# Learning Vite

This repository is a personal sandbox for **learning [Vite](https://vite.dev/)**—how it bundles front-end assets, how it plugs into a Laravel app, and how to run builds and dev servers in everyday workflows.

The stack here is Laravel (with Vite configured via `vite.config.js` and `resources/`) and optional Docker for a consistent PHP and Node environment. Use it to experiment with Vite options, imports, and hot module replacement without affecting production projects.
